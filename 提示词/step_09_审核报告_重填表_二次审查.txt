#### 字段取值规则

| 字段 | 取值来源 | 特殊规则 |
|------|---------|---------|
| 标题 | 🥇 SEO Title → 🥈 Product Name | 自动识别中英文并统一为 `英文  /  中文`；品牌词替换 |
| 样式（Style） | 只看数据列，不看图片 | 无数据则留空 |
| 面料克重 | 原数据列 | 无对应列则留空 |
| 印花方法 | 原数据列 | 如实填写原始数据中的印花方法，格式为 `{英文} / {中文}`。如原始数据无则留空。 |
| FAQ | 原数据列 | 保留原始数据中已有的Q&A，如实转录。不新增、不编造。如原始数据无则留空。 |
| 性别/原产地/省份 | 默认值 | Men / 男士、China / 中国、Zhejiang / 浙江 |
| 类目 | 纯英文 | T-shirt(1) / polo(2) / shirt(3) / Hooded sweatshirt(4) / Non-hooded sweatshirt(5) |

#### 数据获取优先级
1. 审查版各列筛选 → 找最合适数据填入
2. 有固定选项的字段 → 必须从给定选项选择，不能自创
3. 无数据 → 先从图片观察获取视觉信息，再结合数据判断

#### 固定选项映射原则（示例）
- Spread Collar（敞领）→ 本质是翻领 → 选 **Turn-down Collar/翻领**
- Hidden Placket（暗门襟）→ 本质是单排扣 → 选 **Single Breasted/单排扣**
- Button-down Collar（扣领）→ 精确匹配 **Button Down Collar/扣尖领**

#### ⚠️ 字段统一输出格式（必须严格遵守！）

同时有中英文内容的字段，输出格式统一为：
```
{英文内容} / {中文内容}
```
- 英文在前，中文在后
- 分隔符：**空格 + 斜杠 + 空格**（` / `）

**适用字段（需要 英文/中文 格式）：**
- 标题、材质、工艺、样式、长度、领型、袖型、板型、面料类型、产品特性、图案类型、编织方法、印花方法
- 性别、原产地、省份（默认值也要带中文：`Men / 男士`、`China / 中国`、`Zhejiang / 浙江`）
- 所有有固定选项且选项带中英文对照的字段

**不适用字段（不需要 英文/中文 格式）：**
- 类目（纯英文：shirt / polo / T-shirt）
- 纯数值字段（价格、克重、尺寸、重量等）
- 长文本字段（卖点、FAQ，有各自的格式规范）
- 是否废弃（纯中文：废弃/空）

#### 重填版数据列值格式规范（v6.8 新增）

| 字段 | 格式规范 |
|------|---------|
| 价格 | 纯数字+美元符，2位小数：`$110.00`，去掉任何 "USD"、"元" 等后缀 |
| 面料克重 | 纯数字：`180`，去掉 "GSM"、"克" 等后缀 |
| 标题中的 GSM | 紧凑写法：`180GSM`，**不得有空格**（❌ `180 GSM`） |
| 印花方法 | 如实填写原始数据中的印花方法，格式为 `{英文} / {中文}`。如原始数据无则留空。 |

#### 重填版数据行连续性规范（v6.9 新增）

> ⚠️ **数据区域从第 2 行开始必须连续无空行。严禁在数据行之间或末尾插入空白行。** 生成重填表后必须检查：最后一行为最后一个非空数据行，其后不得有空白行残留。


#### 文件命名
`{原文件名}_已审核_重填版_{类目}.xlsx`

#### 未知列处理
第2步识别为"未知列"的列，其数据不写入重填版。在审核报告末尾的【未处理列】章节列出：列名、行号、对应数据内容。由人工判断是否需要纳入重填版。

### 9.3 二次审查

> ⚠️ 二次审查不是走过场，必须把第4-7步的核心检查项重新过一遍，确认第8步的修正都正确应用了。

> ⚠️ **必须实际打开 xlsx 读取**：二次审查时**不得凭记忆或前几步的结论**来判断修正是否正确。必须使用 `read_file` 工具**实际打开重填版 xlsx 文件**，逐行逐列读取修正后的真实值，再与第4-7步记录的问题项逐一对比验证。任何未实际读取文件就声称"已通过"的行为均为违规。

#### 检查清单（15项）
- [ ] 品牌安全复查：是否还有遗漏的品牌词、注册商标材质、不当术语（英文和中文都要查）
- [ ] 属性一致性复查：标题/卖点/FAQ与属性列是否全部一致
- [ ] 图文一致性复查：图文不一致的地方是否已修正
- [ ] 标题格式复查：`英文  /  中文` 格式、英文≤128字符、翻译对应
- [ ] 属性列格式复查：`英文 / 中文` 格式、英文≤50字符、翻译对应
- [ ] 多值属性格式复查：多值属性是否为`英文1, 英文2 / 中文1, 中文2`格式，未被拆分成多个`/`
- [ ] 卖点格式复查：每条2行、半角/全角冒号正确、条间空行、标签对应、中文未丢失、**禁止段落体、禁止 `/` 分隔符、禁止中英文错位**
- [ ] FAQ格式复查：每组4行、英文无中文/中文无英文、组间空行、问答对应
- [ ] 数值保留复查：价格/尺寸/重量等数值数据未被修改、价格列已从原始文件复制
- [ ] 原始数据完整性复查：未被修改的字段是否保持原样（如款式列未被子统一改成同一个值）
- [ ] **材质术语一致性复查（v6.6新增）**：SP/FAQ/标题中所有材质相关词（如 cotton、polyester、modal、wool 等）必须与属性列材质严格一致，不得残留与产品实际材质不符的误导词
- [ ] **SP 列语义复查（v6.10新增）**：逐行验证 Selling Points 中英文标题语义对应（每条 EN 标签与其 CN 标签含义一致）、CN 行无截断/残缺（全文搜索正则 `[\u4e00-\u9fff][A-Z]：` 检测中文后跟大写字母冒号的异常截断模式）、CN 行无整句重复、无品牌词（Supima 等）残片残留
- [ ] **PF 列去重复查（v6.10新增）**：逐行检查 Product Features 列，EN 端和 CN 端均不得出现重复属性项（整词精确匹配）。如有重复，保留首项
- [ ] **双语属性列语义复查（v6.10新增）**：逐行验证 MAT / CRAFT / FT / DESIGN 等中英双语属性列的中英文语义对应，不得出现 EN=CN 语义错位或英文有对应中文无（或反之）

- [ ] **图片提取复查（v6.12更新）**：是否使用 extract_images_v2.py 脚本提取？图片数量是否与源文件行数匹配？0 张时是否已标记"图片缺失"并跳过图文审查？

#### 输出要求
- 必须逐行逐列列出复查结果，不得只给总结论
- 必须引用第8步修正后的新值进行复查，禁止直接复制前几步结论
- AI必须声明："以上二次审查均为AI重新手动检查完成，未直接沿用前几步的结论"
