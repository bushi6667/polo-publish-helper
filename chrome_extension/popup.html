🚀 首次使用引导
  1. 填写下方"发品助手路径"（.html 文件的完整路径）
  2. 点击"打开发品助手"
  3. 在打开的页面右上角点"🔌 扩展设置"，粘贴上方复制的扩展 ID
  4. 在页面里授权 extracted_images 目录（用于 PS 编辑保存）
