# XLSX产品数据审核系统 - 验证清单

## 功能验证
- [x] 品牌词检测：能正确识别注册商标材质词（Coolmax、Lycra、Tencel等）
- [x] 品牌词检测：能正确识别知名品牌名（Nike、Adidas、Polo Ralph Lauren等）
- [x] 品牌词检测：完整词匹配，避免子串误报（"GU"不匹配"Regular"）
- [x] 品牌词检测：大小写不敏感（Nike/nike/NIKE都能识别）
- [x] 材质词验证：能正确匹配材质大全中的安全材质词
- [x] 材质词验证：不在列表中的材质词标记为二级风险
- [x] 风险分级：一级风险（🔴）、二级风险（🟡）、安全（🟢）分类正确
- [x] 审核范围：覆盖标题、卖点、FAQ、材质、面料类型等指定列
- [x] 报告生成：格式符合规范，包含汇总、详情、建议
- [x] 报告生成：问题位置描述清晰（行号+列名）

## 性能验证
- [x] 100行Excel数据审核时间不超过3秒
- [x] 审核过程不阻塞UI操作

## 界面验证
- [x] 审核标签页能正常显示
- [x] 审核按钮点击后能执行审核
- [x] 审核结果按风险等级颜色区分
- [x] 点击问题能跳转到对应产品

- [x] 空Excel数据审核不报错
- [x] 特殊字符（®、™、空格、标点）不影响检测
- [x] 中英文混合文案能正确检测
- [x] 超大Excel文件（500行+）能正常处理
